# UI/UX Product Design

Use this skill when the output affects a user's screen, workflow, trust, or comprehension.

## Workflow

1. Identify the primary user, job-to-be-done, and first successful action.
2. Design the actual usable screen or flow first, not a marketing explanation.
3. Choose controls by function: inputs for data, toggles for booleans, tabs for views, menus for option sets, buttons for commands.
4. Define loading, empty, error, disabled, success, and mobile states.
5. Check text fit, hierarchy, contrast, and repeated-use ergonomics.
6. Prefer restrained, domain-appropriate UI over decorative excess.
