# MAGI Skill References

These MAGI skills follow the public Agent Skills pattern: a folder with a required `SKILL.md` file, YAML frontmatter, and task-specific instructions.

Review these sources:

- Claude Skills overview: https://claude.com/docs/skills/overview
- Claude Code Agent Skills docs: https://docs.claude.com/en/docs/claude-code/skills
- Claude custom skills guide: https://claude.com/docs/skills/how-to
- Anthropic public skills repository: https://github.com/anthropics/skills
- 21st.dev Magic MCP: https://github.com/21st-dev/magic-mcp
- Microsoft Playwright MCP: https://github.com/microsoft/playwright-mcp
- Supabase MCP docs: https://supabase.com/mcp
- Context7 MCP server: https://github.com/truefoundry/context7-mcp-server

The MAGI skill bodies are original project-specific instructions. They are inspired by the Agent Skills file format, not copied from third-party skill contents.
